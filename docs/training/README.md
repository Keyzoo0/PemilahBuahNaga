# Hasil Training

Gambar di folder ini adalah hasil evaluasi model aktif (`core/best.pt`, training
23 Sep 2026) terhadap 125 foto uji, dan ditampilkan di bagian
**📊 Hasil Training** pada [README utama](../../README.md#-hasil-training).

Hasil setiap training baru tersimpan otomatis di `core/runs/<run>/` (10 run
terakhir) dan bisa dilihat di web: **tab Training → Riwayat Training → klik run**.
